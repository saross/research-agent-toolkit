# Claude observations

A register kept by the AI agent, of what it observed about how the user
and the agent work together. **Default-keep:** these are the agent's
working notes, not candidates awaiting approval. The user may read,
answer, or prune them, but by default they persist.

**The axis is the observer.**

| Register | Who observes | What goes in it |
| --- | --- | --- |
| This file | The agent | Its observations of the user's working style and choices, its own self-critiques, and how the collaboration is going, seen from its side |
| The user's own register, if the project keeps one | The user | What the user noticed about the agent, in the user's own words |

Entries take the form `## claude-obs N — YYYY-MM-DD: <one-line summary>`,
with **Pattern.**, **Lesson.**, and **How to apply.** sub-blocks. A
correction is a new entry that cross-references the old one; read entries
are never changed in place.
