# Abductive reasoning investigation

Sequences of surprising fact, probe, and belief revision. Each entry
follows the contract in the reflect skill: a numbered, dated heading
(`## Entry N — YYYY-MM-DD:` and a title), then `**Session:**` and
`**Instance:**` lines, then the sections `### Surprising fact`,
`### Probe`, and `### Belief revision`.
A run with no qualifying episode adds a one-line dated assessment
instead.
