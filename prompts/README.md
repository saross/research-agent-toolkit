# Prompts

Tool-agnostic prompts for research work with language models. They are plain Markdown and work with
any capable model: paste one into a conversation, or adapt it into your own skill or agent.

| Prompt | Use it to |
| --- | --- |
| [`adversarial-results-audit.md`](adversarial-results-audit.md) | Audit a results write-up against its data and analysis, assuming errors exist |
| [`critical-evaluation.md`](critical-evaluation.md) | Evaluate a document or argument critically, claim by claim |
| [`exhaustive-configuration-audit.md`](exhaustive-configuration-audit.md) | Check every setting in a configuration against its intent |
| [`pre-launch-experiment-audit.md`](pre-launch-experiment-audit.md) | Check an experiment before spending money on it |
| [`research-question-refinement.md`](research-question-refinement.md) | Sharpen a research question before designing the study |
| [`writing-self-review.md`](writing-self-review.md) | Get a diagnostic review of your own draft, without having it rewritten |

Each one was developed and tested in the author's own research, and each file ends with notes on
where it came from and what it is for. The `prompt-hardening` plugin in this repository applies the
same techniques to prompts of your own.
